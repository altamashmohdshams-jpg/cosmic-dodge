# 🚀 Cosmic Dodge

Cosmic Dodge is a simple space-themed browser game developed as part of the SSRP Computer Systems recruitment task.

## 🎮 How to Play

- Use the Left Arrow (←) and Right Arrow (→) keys to move the spaceship.
- Avoid the falling asteroids.
- Each successfully avoided asteroid increases the score.
- The game becomes faster as the score increases.
- If an asteroid hits the spaceship, the game ends.
- Click **PLAY AGAIN** to restart the game.

## 🚀 How to Run the Game

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the Left Arrow (←) and Right Arrow (→) keys to control the spaceship.

Alternatively, you can open the project in **Visual Studio Code** and run `index.html` using **Live Server**.
